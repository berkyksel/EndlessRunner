# Endless Runner

Endless Runner, Unity ile geliştirilmiş bir endless runner oyun projesidir. Oyuncu, sabit hatlar arasında hareket eder, engelleri aşar ve skor elde etmeye çalışır.

## Özellikler

- 3 yönlü şerit (lane) hareketi
- Zıplama ve yer kontrolü
- Sonsuz çalışan engel akışı
- Skor ve yeniden başlatma sistemi
- Mobil swipe ve klavye/oyun kumandası giriş desteği
- Unity Input System kullanımı

## Oynanış

- Sol/Sağ yön tuşları veya swipe ile şerit değiştir
- Yukarı tuşu veya swipe ile zıpla
- Engellere çarpmadan mümkün olduğunca uzun süre hayatta kal
- Yüksek skor hedefiyle koşuyu sürdür

## Gerekenler

- Unity 6000.0.32f1 veya uyumlu bir sürüm
- Git için temel araçlar

## Projeyi Açma

1. Unity Hub üzerinden bu klasörü açın.
2. Unity 6000.0.32f1 veya uyumlu sürümü seçin.
3. Proje açıldığında `Assets/Scenes` içindeki sahneyi çalıştırın.
4. Oyun için Play butonuna basın.

## Proje Yapısı

- `Assets/Scenes` : Oyun sahneleri
- `Assets/Scripts` : Oyun mantığı ve kontrol bileşenleri
- `Assets/Player` : Oyuncu ve giriş işlemleri
- `Assets/Prefabs` : Hazır nesneler ve dünya öğeleri
- `ProjectSettings` : Unity proje ayarları

## Geliştirme Notları

Bu proje, endless runner mekaniklerini öğrenmek ve geliştirmek amacıyla oluşturulmuştur. Temel tasarım unsurları şunlardır:

- Şerit tabanlı hareket
- Sürekli ilerleyen dünya
- Kontrol edilen zıplama ve yerçekimi
- Başlangıç/oyun sonu akışı
